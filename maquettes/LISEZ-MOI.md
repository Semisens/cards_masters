# Maquettes

Les maquettes (charte + 5 planches) vivent dans le canvas du projet Claude.
Elles n'ont pas pu être exportées automatiquement dans ce zip.

À faire avant de lancer Claude Code :
1. Ouvre le canvas, exporte chaque planche en PNG (ou PDF).
2. Nomme-les : `01-charte.png`, `02-planche-...png`, etc.
3. Dépose-les dans ce dossier.

Claude Code pourra ensuite lire les images pour respecter les maquettes.
La source de vérité des valeurs (couleurs, rayons, polices) reste `../charte/mastercards-charte.json`.
